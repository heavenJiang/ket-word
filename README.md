## 为什么做单词岛

小学生背单词，最难的不是“看过”，而是第二天、下个月还想得起来。单词书把一千八百个词排成一张清单，孩子翻几页就累了。

单词岛换了个做法：每个词先给一幅画，让孩子**看见**它；再用答题让孩子**想起**它；然后在快要忘记的时候，让它再出现一次。认识的词会变成卡册里的一张卡，学完一座岛，岛上就插上小旗。

## 每个词都有什么

| | |
| --- | --- |
| 🖼 **一幅画** | 画面就是这个词的意思，看图就能猜到：red 是红气球、红草莓和红色消防车。画面里的人物始终是 Lily 和 Max，越看越熟悉 |
| 🔊 **英美发音** | 可以切换英音或美音，听不清就点 🐢 慢速再听 |
| ✍️ **约 3 条例句** | 句子里的词都在 KET 词表内，讲的是 Lily 和 Max 的日常，每句都能播放录音 |
| 🌈 **自然拼读颜色** | 元音组合、不发音的字母用颜色标出，音节用小点隔开，看着就会读 |
| 🎤 **跟读** | 跟着读单词和句子，录下来和原声对比 |
| 💡 **记忆小窍门** | 拆开记、找词缀、别和谁弄混……只给孩子真的记不住的难词 |

## 怎么学：有依据，也不累

- **先看见，再想起**：新词 4 个一组，先看图、听发音、跟读，玩一局配对游戏，做几道别的题之后再回忆一遍。
- **只答题，不自评**：所有复习都是答题，按对错、用时和是否看提示自动打分，孩子不用判断“我会不会”。
- **快忘的时候再见面**：用 FSRS 记忆算法（新版 Anki 用的就是它）给每个词安排复习，最容易忘的先来。新学的词睡一觉再考，同一个词一天最多考一次。
- **认识、听懂、会拼分开记**：三项各有各的记忆进度，家长看得出孩子是“认识但不会拼”，还是“会拼但听不出”。拼写只练约 750 个日常词，KET 用不着每个词都会写。
- **答错当场找回**：答错的词隔几题换一种更容易的题型再来，直到答对；重做不计分，正确率不注水。
- **从认得出到想得起**：同一个词，题目随记忆变牢而变难：听英文选图 → 看英文选中文 → 看中文选英文。
- **跟着 Think 课本走**：岛的顺序对应剑桥 Think 教材（Starter、Think 1、Think 2）的单元，和学校进度对得上。

每一条都有研究依据，详见 [学习模型](docs/learning-model.md)。

## 孩子喜欢的地方

- **航线地图**：48 座插画小岛连成一条航线，Max 站在孩子现在的岛上，学完的岛插上小旗。
- **小狗 Max 会长大**：答对得星星，Max 从小狗长成小队长、探险家，最后当上国王。
- **学完有庆祝**：当天任务做完，今天认识的新卡一张张飞进卡册，打卡日历盖上今天的章，星星够了 Max 当场升级。
- **故事书**：认识了故事里大部分单词，新故事就会打开；读完答对问题还能得星星。
- **卡册和贴纸**：每认识一个词就收集一张卡，三项都掌握就是金卡；坚持学习、读故事还能领到 66 种贴纸。
- **一关一关来**：每 10 题一关，累了可以“今天先到这里”，答过的题都已经保存。

## 给家长

- **只设一个数**：每天学几个新词（默认 10 个）。应用按孩子的答题速度估算每天要学多久、哪天能学完，也可以填一个学完日期，反过来推算每天要学几个。
- **看得见效果**：家长中心用孩子自己的答题记录计算复习时记得的比例、新词隔天还记得的比例、难词比例和实际用时，偏离目标时提示该怎么调；每月还有一次小测。
- **离线可用**：在平板浏览器里“添加到主屏幕”，就像 App 一样全屏打开；可以一次下载全部插画和录音（约 170 MB），之后断网也能学。
- **进度在本机**：不用注册账号。建议每周导出一次备份，换设备时导入。
- **孩子改不了设置**：家长中心在首页右上角，进入前要答一道乘法题。

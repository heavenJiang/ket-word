# KET 单词岛

给小学生的剑桥 A2 Key（KET）背词应用：按官方词表、按话题岛屿学习，每个词分“认识 / 听懂 / 会拼”三项独立记忆，用 FSRS 间隔复习，答题自动评分。

```bash
npm install
npm run dev      # http://localhost:5199
npm test
npm run build
```

## 项目特点：有依据的记忆方法

每个设计都对应一条研究结论，并且用孩子自己的答题数据检验是否真的有效。下表是“为什么这样做”，具体规则见下面的“学习模型”。

| 方法 | 应用里怎么做 | 依据 |
| --- | --- | --- |
| **四条线兼顾** | 刻意背词（单词卡、间隔复习）为主线，例句和故事提供语境输入，“看中文选英文”练“想得起” | Nation 的四条线框架（意义输入、意义输出、语言聚焦学习、流利度）；刻意学单词卡也能形成自动化的词汇知识（Elgort 2011 及后续复现） |
| **主动回忆** | 所有复习都是答题，不是看卡片 | 课堂实验综述：多数研究有中到大的收益，初中课堂效果最大（Agarwal、Nunes、Blunt 2021） |
| **间隔重复** | FSRS 按每张卡的遗忘曲线排期，最容易忘的先复习 | 间隔效应元分析（Cepeda 等 2006）；五年级课堂词汇实验（Sobel、Cepeda、Kapler 2011） |
| **当次重学、隔次再学** | 初见后的练习不计分，课末回忆才计分；答错的题当次换更容易的题型直到答对 | 连续重学：先当次答对，再多次间隔重学，记忆最持久（Rawson、Dunlosky） |
| **从认得出到想得起** | 认识技能按稳定度升级：听英文选图 → 看英文选中文 / 句子填空 → 看中文选英文 | 练“认得出”涨“认得出”，练“想得起”才涨“想得起”（Webb）；只用选择题会高估词汇量约 20%（SAGE Open 2024） |
| **图文双通道、开口说** | 每个词配插画；初见时可以跟读单词和句子，录音回放对比；能识别语音的设备上按读对的词给 1–3 颗星，读对的词标绿、漏读的标橙，读得不好就鼓励再读一次 | 双重编码（Paivio）；大声说出来有助记忆。打分用浏览器的语音识别（iPad Safari、安卓 Chrome，多数需要联网），衡量的是“读得清楚、能被听懂”，不是专业的发音评测 |
| **睡一觉再考** | 新解锁的技能第二天才考；建议晚饭后学 | 儿童学新词后睡眠巩固（Henderson 等 2012；7 岁、12 岁都有效） |
| **多次、多语境见面** | 每词多个例句、填空题、听句子题；故事见过 80% 的词就开放，按 7 / 21 / 60 天推荐重读 | 一个词见 10 次能认、还不会用，需要不同语境反复相遇（Webb 2007） |
| **难词记忆钩子** | 一个词某项技能忘过 2 次，再答错时出现一句中文小窍门（拆开记、词缀、别弄混、藏着的单词，谐音最后才用并提示以录音为准）；约 830 个较难的词有钩子，简单具体词（cat、dog）不配 | 关键词法对四年级左右的孩子有效（研究偏老、样本小），所以只用来救难词；谐音可能把发音带偏，因此排在最后 |
| **自然拼读颜色**（辅助） | 初见和词卡上按拼写规律着色：元音组合、r 控元音、辅音组合、不发音字母（灰），音节用点隔开；答题时不显示 | 系统的自然拼读教学有效（Ehri 等 2001，d = 0.41，一年级后开始效果减半）；“用颜色标”本身只有小规模、无对照的研究，所以只作辅助 |
| **孩子不给自己打分** | 按对错、用时、提示自动评分 | 10 岁左右的孩子普遍高估自己掌握的程度 |
| **量力而行** | 按学完日期和每天分钟数排计划；拼写只练约 750 个 A1 常用词；积压时先追赶复习 | 会写比会认难得多，KET 只要一部分词会写；新词太多，复习会压垮孩子 |

**用数据检验**：研究结论不一定适合每个孩子（例如 Goossens 等 2016 年在常规小学课堂没有复现间隔与回忆练习的效果）。家长中心的“学习效果”从答题记录计算复习回忆率、新词隔天回忆率、难词比例和实际用时，各有目标和调整建议；月度小测每 30 天检验一次“想得起英文”的能力。答题记录攒够后，可以用 FSRS 优化器为孩子拟合专属参数。

**明确不做**：让孩子自评“会不会”；对所有词用谐音联想（证据不够强）；一天突击大量新词；要求全部词都会拼。

## 离线与安装

正式构建（`npm run build`）带 Service Worker（`public/sw.js`）和 Web App Manifest：平板浏览器里“添加到主屏幕”后像 App 一样全屏打开，图标是小狗 Max。

- 程序本身首次访问即缓存，之后没有网络也能打开
- 词库数据联网时取最新、离线时用缓存，新岛屿上线后自动拿到
- 图片和录音用到时缓存；家长中心“离线使用”可一次下载全部（约 1.1 万个文件、170 MB：插画、单词发音、例句录音、故事插图）
- 开发模式（`npm run dev`）不注册 Service Worker，以免缓存挡住修改
- 部署在子路径时（`KET_BASE=/ket/ npm run build`）缓存路径会跟着变

## 学习模型

- **学习计划**（`src/session/goal.ts`）：家长设“学完日期”和“每天学习时间”（默认 25 分钟）。还没学的词平均分到剩下的日子里，最后 21 天只复习、不学新词，并优先复习预计到那天最容易忘的卡；每天重新分配，漏学几天会自动摊开。不设日期时每天固定学 8 个新词。家长中心的“推算这个计划”用应用自己的计划和记忆模型从当前进度往后模拟，给出学完日期和每天用时。
- **每日计划**（`src/session/plan.ts`）：先复习到期的词（覆盖所有已开放岛屿，最容易忘的先来），再学新词：当前岛学完自动接下一座岛。复习按时间预算：新词用剩的时间都给复习，至少占当天 40%；按孩子最近答题的实际速度换算成题数。等着的复习超过半天的量时进入追赶模式：当天暂停新词，复习用满全部时间。
- **新词**：4 个一组：“初见”（插画、发音、音节拆分、例句、跟读录音）→ 不计分的配对游戏 → 不计分的看图练习。这次学习的最后，所有新词再回忆一遍（选中文），这一遍才计分，记忆是在间隔之后测的，不是刚看完就测。听音题和拼写题可用 🐢 慢速重听。
- **三项技能**：认识（看图/选中文）→ 第二天起解锁听音辨词 → 词义进入长期记忆后解锁字母块拼写。拼写只练 Word Atlas 里 A1 级的单个词（约 750 个日常词，构建时标 `spell`），其余的词会认、会听就够 KET 用。各技能各自一张 FSRS 卡片，家长能看出孩子是“认识但不会拼”还是“会拼但听不出”。
- **当次重学**：答错的题隔 3 题换一种更容易的题型再来，直到答对（最多 3 次），重做不计分——答错的词当次就要找回来。
- **题目逐级变难**：认识技能按记忆稳定度出题：不到 3 天听着英文选图，3–10 天看英文选中文或句子填空，10 天以上看中文（配小图）选英文——认得出不等于想得起，后者才是“会用”。
- **学习效果**（家长中心）：用孩子自己的答题检验方法是否有效——复习时记得的比例（目标约 90%）、新词隔天还记得（≥ 80%）、难词比例（< 5%）、每天实际用时；偏离目标时给出该调什么。
- **月度小测**：每 30 天抽 20 个学过一周以上的词，看中文选英文，不影响单词卡，家长中心看逐月变化。
- **记忆钩子**（`content/hooks.json`，`scripts/ket/gen_hooks.py` 用本地 Qwen 思考模式生成）：自动检查保证包含单词本身、不超过 40 字、拆分和词缀的每一部分都是真单词或真词缀并且正好拼成原词、对比词是拼写相近的真单词、谐音写在「」里。人工审核后只保留“藏着真单词”的画面类（already 里有 ready），纯字母形状的联想删掉。
- **自然拼读颜色**（`src/lib/phonics.ts`）：规则加不规则词例外表，按每个词单独切分（短语里 go out 不会出现 oo）。
- **Think 课本路线**（`src/lib/route.ts`）：单词岛按剑桥 Think 第二版的顺序排（Starter → Think 1 → Think 2，每本 Welcome + 12 个单元），每个单元对应它词汇主题的岛，再按语法点穿插核心小岛（Starter 第 1 单元 to be、疑问词 → 我和你）。地图按书和单元列出路线，标出当前岛和下一座；推荐、新词顺序、学完自动换岛都沿着路线走，但所有岛随时都能点进去学。课本各单元的词表没有公开，单元是按主题对应的，一座岛通常比一个单元的词多；后面单元的主题前面学过时显示“复习就好”。
- **学得快可以多学**：当天计划完成后，首页可以“再学 4 / 8 个新词”（当天新词到计划的 2 倍就建议休息，因为多学的词之后都要复习）；设了学完日期时，家长还可以设“每天新词至少几个”，孩子记得快就每天多学，学完日期自然提前，推算会跟着变。
- **分关**：每 10 题一关，关与关之间有小庆祝页（本关星星、还剩几关），可以“再来一关”或“今天先到这里”——答过的题已实时保存。
- **首页**：今日学习分钟的进度环（对照每天计划）和本周打卡；地图分“话题岛 / 核心小岛”两组，标出下一座，单词都见过的岛折叠起来。
- **故事**：只给本岛的词和还没学过的词加下划线（其余学过的词也能点开看卡片）；“从头读到尾”连续朗读，自动翻页。
- **答题记录**：每次计分的作答都记下时间、词、技能、评分和用时（最多 4 万条），用来换算孩子的答题速度，以后也可以用 FSRS 优化器为孩子拟合专属参数。
- **自动评分**：答错 → Again；答对但慢、用提示或拼错一次 → Hard；答对 → Good；拼写又快又准 → Easy。“慢”的阈值按年龄放宽。孩子不需要自己给自己打分。
- **只有首次作答计分**：答错的词隔 3 题换一种题型再练（最多 2 次），重试不计分。
- **公平的干扰项**：内容文件里的 `confusable` 组（如 plate / dish / bowl、dog / puppy）互不作为错误选项，避免图片本身分不清的题。
- **岛屿故事**：每座话题岛有几篇 3 页的小故事（`content/stories/`），主角是 Lily 和 Max。故事里的词见过 80% 就解锁（剩下的词从故事里认识），读过的故事隔 7、21、60 天再推荐重读；阅读时可以点任何学过的词看卡片，或让应用朗读并逐词高亮；读完有 3 道理解题（判断对错、三选一），第一次读完得 5 ⭐ 加答对题数。故事不计入单词记忆，只是又一次和学过的词见面。
- **一词多义**：内容里给多义词列出义项（`senses`），本岛教的意思在前；意思不相关又都要考的（can 罐头 / 能，break，Miss，light）另有一张"新意思卡"（`can.2`），原意思进入长期记忆后才解锁。
- **掌握**：稳定度 ≥ 21 天（三周后仍有约 90% 把握）。该词的各项都掌握 = 金卡。

## 数据流程

```
.local/source/a2-key-vocabulary-list-2025.pdf   官方词表（不入库，从 cambridgeenglish.org 下载）
  └─ scripts/ket/parse_wordlist.py  → data/ket-wordlist.json   词条、词性、例句、英美变体、25 个话题、词组集合
      └─ scripts/ket/build_words.py → data/ket-words.json      规范化（展开 yog(h)urt、a/an，合并重复），标注话题（核心词按 data/core-islands.json 分岛），匹配 Word Atlas
                                    → data/coverage.md         复用与缺口报告
content/topics/<topic>.json          人工审校的儿童内容：中文释义、音节、例句（固定角色 Lily 和小狗 Max）
content/media/svg/<id>.svg           手绘矢量插画（Word Atlas 色板与构图），补 Word Atlas 缺失或不可用的图
  └─ scripts/ket/render_svg.mjs     → content/media/img/       渲染为 512px WebP，统一叠加纸张颗粒质感（需本机 Chrome）
  └─ scripts/ket/gen_comfy.py       → .local/gen/qwen-image/ → content/media/ai/    局域网生图机上的 ComfyUI（Qwen-Image 2512，儿童绘本风格，固定角色形象）按 scene 字段出候选图，--sheet 出联系表人工挑选，--pick 放入，构建时优先于手绘版；新内容攒一批后用 --missing 统一出图
  └─ scripts/ket/gen_images.py      → content/media/ai/        可选：用 OpenAI 兼容的图像 API 生成
scripts/ket/gen_mascot.py           → public/media/ui/         吉祥物小狗 Max 的表情与成长阶段（同一套 Qwen-Image 设置），人工挑选后 --pick 放入
scripts/ket/gen_audio.py            → public/media/sent/       例句录音：局域网 Higgs Audio 合成，Whisper 逐句核对，不合格换种子重录（最多 5 次）
scripts/ket/check_sentences.py      （构建时自动运行）           例句和故事的用词都在 KET 词表内、每个词都有能挖空的句子
content/stories/<id>.json           岛屿故事：页面文字、插图描述（gen_comfy.py 按 story-<id>-<页> 出图）、理解题
  └─ scripts/ket/build_app_data.py  → public/data/             应用数据（自有插画优先于 Word Atlas）
                                    → public/media/            Word Atlas 插画与发音（缓存在 .local/media）
```

话题匹配允许话题表里的复数对应单数词条（shoes → shoe），但复数本身是独立词条时不算（news、shorts）；PDF 未归类或拆分有误的短语在 `build_words.py` 的 `FORMS_OVERRIDE`、`TOPIC_EXTRA` 里手工指定（如 give somebody a call/ring 归通讯科技）。不属于任何话题的 770 个核心词按意思分成 20 座小岛（我和你、小词、在哪里、动起来……），分组写在 `data/core-islands.json`，每岛自带 emoji；新增核心词必须先放进某个岛，否则 `build_words.py` 报错。提前写好、还没开放的岛的内容放在 `content/drafts/`。

`build_words.py` 需要 Word Atlas 数据：把 `https://raw.githubusercontent.com/designfuchen/word-atlas/main/data/word-atlas.json` 放到 `.local/word-atlas/word-atlas.json`。解析脚本需要 `pip install pdfplumber`。

新增一个话题：写 `content/topics/<topic>.json`（格式同 `food.json`），再运行 `npm run data`。构建会校验内容与官方话题词表一一对应、音节拼回原词、易混组只引用本话题的词，并删除不再引用的媒体。

每个词都必须有插画，缺图时构建直接报错；唯一的例外是画不出来的词（a、the、because、believe），内容里写 `"picture": false`，只用 emoji，应用里不出看图题（看图选词换成选中文，听句子选图换成听词，配对游戏显示中文）。插画必须逐张人工核对（用联系表一屏看完）。Word Atlas 面向成人，同形异义和画面偏差都要用 `"atlasImage": false` 屏蔽，例如：

| 词 | 问题 |
| --- | --- |
| bear | Word Atlas 是动词“忍受” |
| can / break | 情态动词“能” / 动词“打破”，KET 食物话题是“罐头” / “课间休息” |
| oil / glass | 插画是石油 / 玻璃板 |
| dish / dessert / pepper | 画面看不出词义 |

已开放：全部 28 座话题岛和 20 座核心小岛，共 2080 张词卡。

## 例句录音（Higgs Audio）

单词发音用 Word Atlas 的真人录音；例句用局域网生图机上的 Higgs Audio v2（端口 7861）预先合成，打包进应用，离线可用。没有录音的句子退回浏览器朗读。

2026-10-29 与之前用的 ChatTTS 对比（36 句，旁白、大人、孩子各 12 句，含 ChatTTS 要多次重录的难句；Whisper 转写比对原句）：Higgs 每句只录 1 次就有 31/36 合格，与 ChatTTS 最多录 5 次取最好的结果持平，旁白和大人 12/12 全对；不再吞掉句尾最后一个词，一句约 2 秒。

- 参数用服务默认值：`temperature=0.3, top_p=0.95, top_k=50, scene_prompt=quiet_indoor`；不合格时换 seed 重录
- 音色按说话人区分（`content/audio/speakers.json`，未列出的句子为旁白），都是内置音色：旁白 `en_woman`（女声），大人对孩子说的话 `en_man`（男声），孩子说的话 `belinda`（音高约 260Hz，语速偏慢）
- 比对时把 Whisper 的美式拼写（Mom、color、favorite、gray）换成内容里的英式拼写，避免误判

运行：`WHISPER_MODEL=<faster-whisper small.en 目录> python3 scripts/ket/gen_audio.py`（需要 `pip install faster-whisper numpy` 和 ffmpeg；模型可从 hf-mirror.com 下载）。已录过且没改动的句子会跳过，改了句子或换了音色会重录。

故事每页也用 Higgs 录音（`scripts/ket/gen_story_audio.py`，旁白音色，按句录、每句 Whisper 挑最好的一遍、句间停 0.35 秒），并用 Whisper 逐词时间戳生成 `marks`，阅读时按播放进度点亮正在读的词；清单在 `content/audio/stories.json`，文件在 `public/media/story/`。没有录音的页才退回浏览器语音。

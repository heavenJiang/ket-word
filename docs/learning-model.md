# 学习模型

每个设计为什么这样做、具体怎么排题和评分。产品介绍见 [README](../README.md)。

## 有依据的记忆方法

每个设计都对应一条研究结论，并且用孩子自己的答题数据检验是否真的有效。下表是“为什么这样做”，具体规则见下面的“学习规则”。

| 方法 | 应用里怎么做 | 依据 |
| --- | --- | --- |
| **四条线兼顾** | 刻意背词（单词卡、间隔复习）为主线，例句和故事提供语境输入，“看中文选英文”练“想得起” | Nation 的四条线框架（意义输入、意义输出、语言聚焦学习、流利度）；刻意学单词卡也能形成自动化的词汇知识（Elgort 2011 及后续复现） |
| **主动回忆** | 所有复习都是答题，不是看卡片 | 课堂实验综述：多数研究有中到大的收益，初中课堂效果最大（Agarwal、Nunes、Blunt 2021） |
| **间隔重复** | FSRS 按每张卡的遗忘曲线排期，最容易忘的先复习 | 间隔效应元分析（Cepeda 等 2006）；五年级课堂词汇实验（Sobel、Cepeda、Kapler 2011） |
| **当次重学、隔次再学** | 初见后的练习不计分，课末回忆才计分；答错的题当次换更容易的题型直到答对 | 连续重学：先当次答对，再多次间隔重学，记忆最持久（Rawson、Dunlosky） |
| **从认得出到想得起** | 认识技能按稳定度升级：听英文选图 → 看英文选中文 / 句子填空 → 看中文选英文 | 练“认得出”涨“认得出”，练“想得起”才涨“想得起”（Webb）；只用选择题会高估词汇量约 20%（SAGE Open 2024） |
| **图文双通道、开口说** | 每个词配插画；跟读单词和句子（录音回放、和原声对比）暂时关闭，等发音评测做好后一起开放：浏览器的语音识别判断不了发音好坏 | 双重编码（Paivio）；大声说出来有助记忆。 |
| **睡一觉再考** | 新解锁的技能第二天才考；建议晚饭后学 | 儿童学新词后睡眠巩固（Henderson 等 2012；7 岁、12 岁都有效） |
| **多次、多语境见面** | 每词多个例句、填空题、听句子题；故事见过 80% 的词就开放，按 7 / 21 / 60 天推荐重读 | 一个词见 10 次能认、还不会用，需要不同语境反复相遇（Webb 2007） |
| **难词记忆钩子** | 一个词某项技能忘过 2 次，再答错时出现一句中文小窍门（拆开记、词缀、别弄混、藏着的单词，谐音最后才用并提示以录音为准）；约 830 个较难的词有钩子，简单具体词（cat、dog）不配 | 关键词法对四年级左右的孩子有效（研究偏老、样本小），所以只用来救难词；谐音可能把发音带偏，因此排在最后 |
| **自然拼读颜色**（辅助） | 初见和词卡上按拼写规律着色：元音组合、r 控元音、辅音组合、不发音字母（灰），音节用点隔开；答题时不显示 | 系统的自然拼读教学有效（Ehri 等 2001，d = 0.41，一年级后开始效果减半）；“用颜色标”本身只有小规模、无对照的研究，所以只作辅助 |
| **孩子不给自己打分** | 按对错、用时、提示自动评分 | 10 岁左右的孩子普遍高估自己掌握的程度 |
| **量力而行** | 按学完日期和每天分钟数排计划；拼写只练约 1000 个 KET 要写的词；积压时先追赶复习 | 会写比会认难得多，KET 只要一部分词会写；新词太多，复习会压垮孩子 |

**用数据检验**：研究结论不一定适合每个孩子（例如 Goossens 等 2016 年在常规小学课堂没有复现间隔与回忆练习的效果）。家长中心的“学习效果”从答题记录计算复习回忆率、新词隔天回忆率、难词比例和实际用时，各有目标和调整建议；月度小测每 30 天检验一次“想得起英文”的能力。答题记录攒够后，可以用 FSRS 优化器为孩子拟合专属参数。

**明确不做**：让孩子自评“会不会”；对所有词用谐音联想（证据不够强）；一天突击大量新词；要求全部词都会拼。

## 学习规则

- **学习计划**（`src/session/goal.ts`）：家长只设“每天新词 N 个”（默认 10）。每天的任务 = N 个新词 + 到期的复习，复习不按时间截断，学完当天的词就算完成；只在几天没学、复习积压时一天最多 150 题并暂停新词先追赶。家长中心按孩子的答题速度把计划往后模拟，显示预计学完日期和每天大约多少分钟（只作参考，比如每天 10 个约 6 个月学完、每天约 28 分钟）。“学完日期”可选：填了会反推每天需要几个新词（一键套用），最后 21 天复习对准这一天。
- **每日计划**（`src/session/plan.ts`）：先复习到期的词（覆盖所有已开放岛屿，最容易忘的先来），再学新词：当前岛学完自动接下一座岛。复习按题数算、不按时间截断：当天到期的都排进来，一天最多 150 题；等着的复习比当天剩余名额多出 75 题以上时进入追赶模式，当天暂停新词、只做复习。用时只是按孩子最近的答题速度给家长看的估计。
- **新词**：4 个一组，排在一次学习的前面、穿插在复习之间：“初见”（插画、发音、音节拆分、例句；跟读暂时关闭）→ 不计分的配对游戏 → 不计分的看图练习 → 做几道复习 → 这组词再回忆一遍（选中文），这一遍才计分，记忆是在间隔之后测的。一组新词回忆完之前不会出现关卡休息；这时点 ✕ 会先问一句“做完这组再走吧？”，坚持离开的话，这组还没回忆的词不记入进度，下次当新词重新认识。听音题和拼写题可用 🐢 慢速重听。
- **三项技能**：认识（看图/选中文）→ 第二天起解锁听音辨词 → 听音答过一次后，再隔一天解锁字母块拼写（一般是学词后第 3 天，趁图和音还新鲜；新解锁技能的第一次练习排在同一词当天到期、但还没逾期的复习前面，那道复习推到第二天）。拼写只练 KET 真要孩子写出来的词（构建时标 `spell`，规则见 `content/spell.json`）：Word Atlas 的 A1 词；所有语法词（限定词、代词、介词、连词、情态/助动词，阅读 Part 5 填空考的就是这些）；以及 Word Atlas 没给级别的日常词（数字、家人、happy、go 等，听力 Part 2 记笔记常要写）。词组、第二词义、单字母词、缩写（CD、a.m.）和感叹词不拼。其余 A2 词考试里主要是读和听，会认、会听就够。各技能各自一张 FSRS 卡片，家长能看出孩子是“认识但不会拼”还是“会拼但听不出”。
- **一天只考一次**：记忆模型不用“同一天内的短期复习步”，第一次计分后最早第二天再考（答错 1 天、勉强 2 天、答对 3 天、又快又好 8 天）；复习按天算，当天到期的不管几点学都算今天；同一个词一天最多考一项（认识、听懂、拼写里最容易忘的那项），其余顺延一天。课堂内的重学由“答错换题再来”和课末回忆完成。
- **当次重学**：答错的题隔 3 题换一种更容易的题型再来，直到答对（最多 3 次），重做不计分——答错的词当次就要找回来。
- **题目逐级变难**：认识技能按记忆稳定度出题：不到 3 天听着英文选图，3–10 天看英文选中文或句子填空，10 天以上看中文（配小图）选英文——认得出不等于想得起，后者才是“会用”。
- **学习效果**（家长中心）：用孩子自己的答题检验方法是否有效——复习时记得的比例（目标约 90%）、新词隔天还记得（≥ 80%）、难词比例（< 5%）、每天实际用时；偏离目标时给出该调什么。
- **月度小测**：每 30 天抽 20 个学过一周以上的词，看中文选英文，不影响单词卡，家长中心看逐月变化。
- **记忆钩子**（`content/hooks.json`，`scripts/ket/gen_hooks.py` 用本地 Qwen 思考模式生成）：自动检查保证包含单词本身、不超过 40 字、拆分和词缀的每一部分都是真单词或真词缀并且正好拼成原词、对比词是拼写相近的真单词、谐音写在「」里。人工审核后只保留“藏着真单词”的画面类（already 里有 ready），纯字母形状的联想删掉。
- **自然拼读颜色**（`src/lib/phonics.ts`）：规则加不规则词例外表，按每个词单独切分（短语里 go out 不会出现 oo）。
- **Think 课本路线**（`src/lib/route.ts`）：单词岛按剑桥 Think 第二版的顺序排（Starter → Think 1 → Think 2，每本 Welcome + 12 个单元），每个单元对应它词汇主题的岛，再按语法点穿插核心小岛（Starter 第 1 单元 to be、疑问词 → 我和你）。地图是一条从上往下蜿蜒的航线（每座岛用一张代表它的词图做封面，见 `src/lib/islands.ts`，画不出来的核心小岛借用意思相近的图）：三本书是三段航线，岛按学习顺序排开，外圈是进度环，Max 站在当前岛上，下一座发光，单词都见过的岛插上小旗；打开时自动滚到当前岛，点一座岛先看预览（几张词图、已认识几个）再决定去不去，避免误触换岛。课本单元的对应关系只在首页的当前岛下面小字显示；推荐、新词顺序、学完自动换岛都沿着路线走，但所有岛随时都能点进去学。课本各单元的词表没有公开，单元是按主题对应的，一座岛通常比一个单元的词多；后面单元的主题前面学过时显示“复习就好”。
- **学得快可以多学**：当天计划完成后，首页可以“再学 4 / 8 个新词”（当天新词到计划的 2 倍就建议休息，因为多学的词之后都要复习）；想长期多学就调高“每天新词”。
- **打卡日历**：首页本周打卡可以点开月历，学过的日子盖章（颜色深浅按当天题数），显示本月学习天数、现在连续和最长连续天数，点某天看当天答题、新词和星星。
- **学完的庆祝**：当天任务做完时，今天认识的新卡一张张飞进卡册（只复习的日子换成找回的老朋友），本周打卡条给今天盖章并显示连续天数，星星够了 Max 当场升级；点一下屏幕可跳过，系统设了“减少动画”时直接显示结果。
- **分关**：每 10 题一关，关与关之间有小庆祝页（本关星星、还剩几关），可以“再来一关”或“今天先到这里”——答过的题已实时保存。
- **首页**：底栏只有首页、地图、故事、卡册四栏；家长中心不常用，入口是首页右上角的“家长”小按钮（进入前要答一道乘法题）。今日进度环按**任务数**计（新词 + 排到今天的复习，来自每天的数量限制），不是按分钟：当天的词学完环就满，不会再说“还差多少学习时间”（#2）；已用时间只作为一句参考显示。旁边是本周打卡。首页顶部是一个小场景：蓝天白云、连续天数和星星徽章、当前岛的插画小岛（点它去地图），Max 站在岛边说今天要做什么；下面的主卡片摆着今天要学的词的插画（“今天会认识它们”）和开始按钮。打卡日用小狗爪印 🐾 盖章；Max 成长卡并排显示现在的 Max 和“下一个样子”，以及还差几颗星。
- **故事**：只给本岛的词和还没学过的词加下划线（其余学过的词也能点开看卡片）；“从头读到尾”连续朗读，自动翻页。
- **答题记录**：每次计分的作答都记下时间、词、技能、评分和用时（最多 4 万条），用来换算孩子的答题速度，以后也可以用 FSRS 优化器为孩子拟合专属参数。月度小测答错毕业词时记的那一次“忘了”单独标记（类型 3），不算进复习回忆率、答题速度和当天题数。
- **自动评分**：答错 → Again；答对但慢、用提示或拼错一次 → Hard；答对 → Good；拼写又快又准 → Easy。“慢”的阈值按年龄放宽。孩子不需要自己给自己打分。
- **只有首次作答计分**：每个词每项技能在一次学习里只有第一次作答计分，“当次重学”的重做都不计分。
- **公平的干扰项**：内容文件里的 `confusable` 组（如 plate / dish / bowl、dog / puppy）互不作为错误选项，避免图片本身分不清的题。另外，中文释义里有相同义项的词（maybe / perhaps 都是“也许”，thanks / thank 都是“谢谢”）自动不当错误选项，否则会有两个对的答案；只有听音辨词例外，因为那道题只比读音。
- **故事书页面**：最上面只推荐一本——能读的新故事，否则该重读的，否则沿着学习路线最先能打开的那本（列出还差的词，并能一键去那座岛）；推荐卡上写着几页、几道题、最多得几颗星。下面是两层可以横向滑动的书架：“我的书架”（能读和读过的，读过的用星星显示答对几题，该重读的标“再读一遍”）和最多 6 本“快要打开的故事”（彩色封面加“还差 N 个词”标签和进度条），其余只给数量，不摆一墙锁。
- **岛屿故事**：每座话题岛有几篇 3 页的小故事（`content/stories/`），主角是 Lily 和 Max。故事里的词见过 80% 就解锁（剩下的词从故事里认识），读过的故事隔 7、21、60 天再推荐重读；阅读时可以点任何学过的词看卡片，或让应用朗读并逐词高亮；读完有 3 道理解题（判断对错、三选一），第一次读完得 5 ⭐ 加答对题数。故事不计入单词记忆，只是又一次和学过的词见面。
- **一词多义**：内容里给多义词列出义项（`senses`），本岛教的意思在前；意思不相关又都要考的（can 罐头 / 能，break，Miss，light）另有一张"新意思卡"（`can.2`），原意思进入长期记忆后才解锁。
- **掌握**：稳定度 ≥ 21 天（三周后仍有约 90% 把握）。该词的各项都掌握 = 金卡。
- **毕业**：稳定度 ≥ 180 天（半年后仍有约 90% 把握）的卡片不再安排日常复习，各项都毕业的词在卡册里显示 🎓；最长复习间隔 365 天。三道保险：考前 21 天冲刺时，预计考试当天会弱的毕业卡照样拉回来；月度小测答错的毕业词按“忘了”记一次，回到复习；故事里继续在语境中遇到。依据：长期外语词汇研究（Bahrick 等）发现间隔足够长、学得足够牢的词可以保持多年；复习间隔应和要记住的时长相匹配（Cepeda 2008）。模拟（每天 10 个新词、复习不设上限）：第二年每天约 30 题，原来上限 120 天、没有毕业时约 70 题且降不下来。
